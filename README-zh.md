# OneSpec

> English version: [README.md](README.md)

OneSpec 是一个给 Codex 使用的 skill 包，用来执行 OpenSpec + Superpowers 工作流。

## 安装

任选一种方式安装。

### 通过 `npx`

如果你已经把包发布到 npm：

```bash
npx @kafka0102/onespec init
```

### 通过仓库源码

直接从这个仓库安装英文 skill bundle：

```bash
npx skills add kafka0102/onespec/tree/main/assets/skills-en -a codex -y
```

安装中文 skill bundle：

```bash
npx skills add kafka0102/onespec/tree/main/assets/skills -a codex -y
```

## 使用

安装后重启 Codex，然后在任务里调用 OneSpec skills 即可。
